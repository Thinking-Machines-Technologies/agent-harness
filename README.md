# 🧠 Thinking Machines Technologies

> Foundational agentic infrastructure and modular harnesses for next-generation AI systems.

## 🚀 Overview
**Thinking Machines Technologies** is an open-source initiative focused on bridging the gap between raw Large Language Models (LLMs) and real-world execution environments. We build lightweight, transparent, and extensible agent harnesses.

## 📦 Projects / Core Modules
- **`agent-harness`** *(Current)*: A zero-bloat, highly modular Python harness implementing the ReAct loop, tool calling, and local model orchestration (Ollama/vLLM).
